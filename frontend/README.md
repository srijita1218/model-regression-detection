# ModelWatch Frontend

The frontend for ModelWatch, a model regression detection system.

ModelWatch is designed to detect quality regressions in LLM-powered features when prompts or model configurations change.

## Tech Stack

- Rust
- Leptos
- WebAssembly (WASM)
- Trunk
- CSS

## Running the Frontend

Make sure Rust and Trunk are installed.

From the `frontend` directory:

```powershell
cargo check
